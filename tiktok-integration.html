Die TikTok-Verbindung.
Einfach erklärt.

Eine transparente Übersicht darüber, warum AutoCut Studio eine TikTok-Verbindung anbietet, welche Berechtigungen benötigt werden und welche Grenzen diese Integration hat.

Warum TikTok verbinden?

Die TikTok-Anbindung befindet sich in der Erprobung; ein erfolgreicher produktiver End-to-End-Test ist noch nicht bestätigt. Nach deiner Zustimmung soll AutoCut Studio Informationen über das verbundene TikTok-Konto und dessen öffentliche Videos abrufen. Damit lässt sich ein lokal bearbeiteter Clip später seiner tatsächlichen TikTok-Veröffentlichung zuordnen. Die Zuordnung wird vom Benutzer bestätigt.

So läuft die Verbindung ab

  1. Der Benutzer wählt in AutoCut Studio den gewünschten TikTok-Kanal aus.
  2. AutoCut öffnet die offizielle TikTok-Autorisierung im Browser.
  3. Der Benutzer meldet sich bei TikTok an und genehmigt die angezeigten Zugriffsrechte.
  4. TikTok leitet die Bestätigung an die Desktop-Anwendung zurück.
  5. Der Benutzer wählt später ein lokales Video und die zugehörige veröffentlichte TikTok-Version aus. Alternativ kann eine Video-ID oder ein TikTok-Video-Link verwendet werden.
  6. AutoCut prüft die Kontozugehörigkeit über die TikTok-Schnittstelle und nutzt den Veröffentlichungszeitpunkt von TikTok.

Benötigte Berechtigungen

user.info.basic

Berechtigung für grundlegende Kontoinformationen. Der untersuchte Adapter führt bisher keinen gesonderten User-Info-API-Abruf aus; die Kontokennung kann bereits aus der OAuth-Antwort stammen.

video.list

Lesen der Liste und Metadaten öffentlich veröffentlichter Videos des autorisierten Kontos, um ein bestimmtes Video zuzuordnen.

Was die Integration nicht macht

  • Sie erfordert keine Eingabe deines TikTok-Passworts auf dieser Webseite.
  • Sie postet über die Display API keine Videos automatisch auf TikTok.
  • Sie verknüpft ein Video nicht automatisch nur aufgrund eines ähnlichen Titels.
  • Sie ermöglicht keinen Zugriff auf Konten, deren Inhaber die Autorisierung nicht erteilt haben.

Lokale Datenspeicherung und aktueller Stand

Nach erfolgreicher Verbindung werden TikTok-Tokens in der lokalen Datenbank mit Windows-DPAPI verschlüsselt gespeichert. Video-Metadaten und Leistungswerte werden lokal verwaltet. Ein Kontotrennvorgang entfernt nicht automatisch sämtliche gespeicherten Statistiken und Backups. Die Funktion ist im Code implementiert, wurde aber im geprüften Stand noch nicht mit einer echten freigegebenen TikTok-App Ende-zu-Ende nachgewiesen.

Verbindung trennen und Datenschutz

Die Autorisierung für externe Apps kann in den entsprechenden TikTok-Kontoeinstellungen verwaltet beziehungsweise widerrufen werden. Informationen zur Verarbeitung in AutoCut, zur Speicherdauer und zu Löschanfragen findest du in unserer Datenschutzerklärung. Für Anfragen gibt es einen Kontaktweg.

Hinweis: AutoCut Studio ist eine eigenständige Anwendung und kein offizielles Produkt von TikTok. Die Verfügbarkeit der Funktionen hängt von der Freigabe der benötigten TikTok-Schnittstellen ab.

Technical overview for app reviewers (English)

AutoCut Studio is a Windows desktop video editor. Its optional TikTok integration uses Login Kit to obtain the account holder’s permission, then uses the Display API with user.info.basic to identify the authorized account and video.list to fetch information about that account’s public videos. The user manually associates a locally edited video with a specific published TikTok video. The integration does not post videos to TikTok.

The app requests authorization through TikTok’s official consent flow, not through a password form on this site. Users may revoke app access through TikTok. OAuth tokens are encrypted locally using Windows DPAPI. The integration is implemented but a successful live end-to-end connection has not yet been confirmed. An actual demonstration must be recorded before submission to TikTok review.

Auf einen Blick

  • Plattform: Windows-Desktop
  • Authentifizierung: TikTok Login Kit
  • Videos: TikTok Display API
  • Scopes: user.info.basic, video.list
  • Posting: nicht Teil dieser Integration
